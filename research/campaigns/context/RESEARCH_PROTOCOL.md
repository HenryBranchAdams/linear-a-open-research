# Research protocol

**Consolidated after iteration 041, 23 October 2026.** This document gathers the existing mission and accepted methodological clarifications into one current procedure. It does not change the scientific acceptance standard.

## Mission and useful intermediate results

Establish one Linear A construction whose action and relevant participant roles have independent support and distinguish serious competing analyses.

A supported local category or administrative relationship is useful intermediate progress. A fluent English sentence is not an evidential criterion. A finite test need not start with an already-known historical name or an arbitrary minimum number of objects.

## Report the level actually reached

| Level | What can be claimed |
| --- | --- |
| Access | A source was obtained or a finite route failed. |
| Reading and object control | Exact carrier, signs, damage, erasures, grouping, physical context or source qualifications improved. |
| Structural or physical constraint | A defined model or operation order is constrained under stated assumptions. |
| Semantic discrimination | An independently established observation changes comparison of grounded meanings or relationships. |
| Linguistic replication | A frozen rule succeeds on genuinely unused independent evidence, with exposure and selection recorded. |
| Mission construction | The action and relevant participant roles are independently supported, with appropriate validation. |

Do not move a result up this ladder because more researchers agree, arithmetic closes or software checks pass. A null semantic result does not erase a useful lower-level finding.

Select work based on a changed evidence opportunity, or declare a finite discovery task seeking one. Historical campaign-specific time limits and stops are not perpetual instructions to rerun that campaign.

## Admission to a semantic test

Before inspecting the proposed test outcome, record:

1. Exact carrier and written component, with reading branches material to the claim.
2. A narrow proposed category, relationship, action or role.
3. Serious alternatives grounded in the context, including the strongest surviving rival.
4. An independently observed relation and differing, constrained predictions.
5. Actual evidence route, acquisition scope, analysis rule and finite stop.
6. Prior source/outcome exposure, dependence and any unused test to be held back.
7. Decision criteria, including what remains unresolved after each possible outcome.

Use the [iteration brief template](../templates/ITERATION_BRIEF.md). A bounded source-discovery task may precede this gate; it is not thereby an admitted semantic experiment.

Some roles can coexist. Narrow the claim until the predictions genuinely differ. A hypothetical account/owner story does not veto all comparative support without contextual grounding and a constrained prediction. Conversely, positive technical evidence can make a production explanation a serious rival even when no workshop is named.

Comparative support can be graded. Compatibility does not imply equal probabilities. Do not invent probability scores when there is no justified model.

## Source and identity controls

Preserve raw acquisitions and frozen snapshots. Add explicit correction overlays; do not silently edit the underlying corpus. Record the original wording, exact locator, access level and dependency for each observation.

Distinguish page text, figure caption, actual pixels, specialist-reported autopsy and newly performed physical examination. A successful image request is not evidence that the returned pixels were inspected. Keep source-reported chronology attributed unless the decisive surface relationship was directly checked.

Database chunks need not be whole words. Different faces need not be independent objects. Component uncertainty remains relevant when a composite is called certain. Site, period, hand, commodity, layout, document class, manufacture, capacity and contents may confound a comparison.

Keep inventory, catalogue, sherd, sample and laboratory-code namespaces separate until a documentary bridge joins them. Nearby finds and general site-level results do not become exact-object use evidence. Later use must be linked to the marking event at the scope of the proposed interpretation.

A device-use network does not by itself identify one individual. Maker, inscriber, seal operator, responsible institution, counterparty and written referent are distinct variables. The same designation/account and the same historical person are different identity claims.

## Exposure and independence

Track source independence, object/event independence and inferential independence separately. A mirror and its original edition are one source lineage. New publications or investigators do not multiply ancient carriers or establish new transactions.

The [baseline exposure ledger](../baseline/EXPOSURE_LEDGER.json) is a minimum record of known exposure, not a comprehensive unseen-object register. Absence means unknown, not unexposed. Later campaign exposure and source-led adaptations are in their protocols and decision logs.

Freeze a surviving rule before testing genuinely unused evidence. A retrospective split or leave-one-out calculation cannot reverse prior exposure. If new source information changes the rule during analysis, label the change discovery and use another genuinely unused test if independent validation is claimed.

## Analysis and review

Select linked records using evidence independent of the proposed morphology or translation. Remove the proposed target from overlap scores. Check common-label, damaged-reading, unit, scope and layout alternatives when they can change the decision.

Report negative searches within the actual inspected corpus and acquisition routes. Failure to recover a join is not proof that no register exists; access failure is not refutation of an unread source. Arithmetic compatibility is conditional on a specified accounting model, not a translation.

Use one active deep candidate and an independent challenger until the admission decision is clear. Parallelize genuinely independent source tasks. The challenger should reconstruct the inference, inspect the decisive evidence at the stated level and test the strongest alternative. Record disagreements and their adjudication. New reviewers do not create blind ancient evidence.

## Stop and reopen

Stop when the finite packet adds no decision-changing observation, an access route is exhausted or the proposed test cannot distinguish its grounded alternatives. Preserve the narrow reason and exact evidence that would reopen it.

Another compatible paraphrase, unchanged calculation, repeated metadata search or extra source host does not reopen a branch. Better reading or source access can be a legitimate lower-level task; state its purpose and limits.

## Finish each iteration

Create a numbered iteration only for actual new research work. A documentation cleanup receives a documentation revision, not a new scientific iteration.

Preserve the report, state delta, source/access ledger, raw data or capture hashes, method and outputs, evidence overlays, review/adjudication and continuation. Append scientific registry entries only when warranted; do not rewrite historical entries to erase overclaims.

Update the current state, queue, status metadata, history/changelog and relevant guardrails together. Check current links, claim/source IDs and counts, then refresh the portable manifest and run its current verifier. Original campaign verifiers run only in their original snapshots.

Report what changed, the strongest surviving rival, the actual evidence level and the next decision-changing observation. Distinguish research verification from packaging checks and publication status.

## D2026-10-26 clarification after C044

A graded local category preference can be retained when independent archaeological morphology changes comparative support. State its bridge explicitly: a pictured prototype is not automatically an exclusive material rule for counted referents. Keep that distinction separate from event scope and participant roles. C044’s `graded_semantic_preference` is true while its established-binding `new_semantic_relationship` remains false. This records useful support without upgrading it to linguistic replication or the full mission; it does not change the existing acceptance standard.
