# Reproduce C042

From this campaign directory:

```bash
python3 analysis/capacity_comparison.py
python3 agents/challenger/C042_REVIEW_CALCULATIONS.py
```

Both programs use the Python standard library. The main program loads its source-qualified input file, checks the frozen analysis-rule hash, then regenerates JSON/CSV sensitivity results. The challenger program independently reconstructs the finite arithmetic and conditional geometry. These are model checks, not software validation of an ancient meaning.

The main analysis rule predates the107 source correction and receipt of ZA values by that analyst; the later source updates remain visible. The geometric envelope was added after source-image inspection, under explicit assumptions. No output is a statistical confidence statement, newly measured capacity, unit discovery or unused validation result.

`evidence/raw_discovery_records.json` retains the exact two rows from the1721-record frozen corpus. `evidence/READING_AND_OBJECT_OVERLAY.json` applies scoped source corrections without rewriting those rows. Detailed exposure-scan code/output and original agent criteria remain in their own files. Historical paths in agent logs describe the working directories at the time; the acquisition ledger records which raw sources are retrievable by URL rather than bundled.

The top-level current `verify.py` checks archive preservation, inherited record prefixes, new references and navigation. The D2026-10-23 verifier is pinned inside its exact original zip and should be run only in that snapshot. Preservation checks establish integrity, not the truth of source transcriptions or interpretations.
