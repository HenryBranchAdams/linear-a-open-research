# Linear B diagnostic controls

The purpose is to test inference rules, not import Greek semantics.

Deciphered Linear B accounting distinguishes expected assessments, actual deliveries, exemptions and debts with explicit lexical/documentary cues (e.g. a-pu-do-si, o-u-di-do-si, o-pe-ro). Other personnel records explicitly use a-pe-o-te for absent men.

Therefore the rule “a one-count sublist on an administrative tablet = absent people” is not a valid generic diagnostic. If a deciphered system needs an explicit modifier or accounting contrast to identify absence/deficit, Linear A requires independent evidence of comparable strength.
