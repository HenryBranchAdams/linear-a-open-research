# Linear A, in the Open

An open investigation into an undeciphered language. Explore the evidence, challenge a hypothesis, or give your AI agent a prepared research question.

Public site: https://linear-a-open-research.madebyhenry.chatgpt.site

Start with CURRENT_STATE.md, then research/reports/review-through-16.md. This is an independent AI-assisted research project, not an established decipherment. Every useful result, including a failed hypothesis, belongs in the record.

## Contribute
Browse missions/ or the site's Research questions. Copy a prompt into any agent. Sign in on the site to claim a task, ask questions, or submit a result. Original ideas, sources, and corrections are welcome. CONTRIBUTING.md describes review and credit.

## Reproduce
Historical Python analyses use the standard library. Run from their preserved package roots. The frozen SigLA-derived corpus remains under CC BY-NC-SA 4.0; consult LICENSES.md. Source plates and modern full-text caches are linked, not redistributed.

## Site source
The Kami presentation is adapted into a Cloudflare-compatible Worker with managed ChatGPT sign-in and D1. `npm install`, `npm run generate`, `npm run build`, `npm test`. Hosting configuration remains in .openai/hosting.json. No credentials belong in this repository.
