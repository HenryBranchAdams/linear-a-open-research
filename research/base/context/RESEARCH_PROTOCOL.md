# Research protocol

## Mission
Establish one Linear A construction whose action and relevant participants’ roles are supported independently and which discriminates competing analyses.

## Evidence levels
1. **Reading:** signs, damage, dividers, erasures, face continuation.
2. **Category:** commodity, person-like designation, place-like designation, numerical operator.
3. **Identity:** same designation/account versus same historical person. Keep distinct.
4. **Role/action:** source, recipient, responsibility and an expressed action; do not infer them from proposed endings.
5. **Construction:** independent replication or genuine prediction on unused evidence.

## Required research record
Each claim has a stable ID, witnesses, evidence/access level, dependencies, strongest rival, current disposition, and a discriminating next observation. Each experiment has an ID, inputs, exact method, outputs, limitations and novelty classification. Retain rejected models and the narrow conditions of their rejection.

## Source controls
- Preserve raw acquisition snapshots; correction overlays never silently overwrite them.
- Database sequence chunks are not necessarily complete words; opposite faces are not independent objects.
- Record component-level uncertainty even when a composite is called certain.
- A mirror, a database and a later discussion can reproduce one edition; they are not independent confirmations.
- A same-seal link identifies an instrument/use network before it identifies one individual.
- Site, hand, period, commodity, document type and layout are possible confounds.
- Bibliographic priority is separate from a new project calculation.

## Analysis controls
- Select linked records using evidence other than the proposed morphology.
- Remove the proposed target from overlap scores; run common-label and damaged-reading sensitivity checks.
- Verify top discovery candidates against edition context before any semantic inference.
- Report negative searches only within the actual captured corpus.
- Retrospective leave-one-out consistency is not an independent held-out prediction.
- Numerical compatibility is necessary in a specified accounting model, not a translation.
- Software checks validate computation and packaging, not decipherment.

## Iteration lifecycle
Read START_HERE.md, context/CURRENT_STATE.md, context/DO_NOT_REUSE.md, and the latest report. Consult registry claims and experiments before selecting work. Place new work under iterations/NNN; append the chronology and update current state. Archive source bundles unchanged. Reproduce outputs and review conclusions before saving the next checkpoint.

## Stopping and pivoting
A candidate advances only when new observable evidence discriminates a rival. If reading or context remains inaccessible, mark that barrier explicitly. Additional rephrasings of compatible English sentences do not advance the claim. A completed bounded search with no qualifying result is a valid experiment, not proof that no solution exists.
